# Curriculum source and sequence

The weekly plan is generated by `scripts/rebuild-curriculum.mjs` for the **AUT
Master of Cyber Security and Digital Forensics** (AK1324). Re-run the script and
then `npm run check:data` after any change.

## What is scheduled

Only the **cybersecurity and digital forensics track (C)** is scheduled, as 220
checkpoints across 72 study blocks. Every checkpoint is tagged **Beginner,
Intermediate or Advanced** (shown as a badge), progressing within each group. The
data engineering (A), GenAI (B) and coding/interview (D) tracks are kept as
**optional, unscheduled** material in the Topic atlas for brush-up on any day; the
R track and the data-science statistics/ML material have been removed.

The track now covers the compulsory courses, the likely electives (COMP830
cryptography, COMP833 network security, COMP821 information security, INFS803
cloud, COMP816 IoT), and market-demand skills AUT touches only lightly:
a from-scratch scripting ladder (Python, Bash, PowerShell), Microsoft
Sentinel/KQL detection engineering, AI security, malware analysis and reverse
engineering, the compliance frameworks NZ employers name (ISO 27001, CIS,
NZISM), Active Directory and Microsoft identity, security data engineering, the
entry certifications NZ listings name (Security+/ISC2 CC, eJPT/PJPT, BTL1,
SC-200, then OSCP), and an NZ job-search group scheduled in the first weeks
because the main graduate and internship round runs from March to April. The blockchain elective (COMP842) is intentionally not
covered.

## Sequence (balanced: job-ready skills + masters coursework)

The nine phases of eight blocks each pair practical, employable skills with the
matching AUT coursework:

1. Foundations, networking & systems — CIA, risk, home lab, TCP/IP, DNS, TLS, Wireshark, Linux/Windows, scripting.
2. Secure coding & cryptography — input validation, auth/session design, primitives, PKI (COMP830).
3. Web security & offensive labs — OWASP Top 10, PortSwigger labs, authorized testing and reporting.
4. SOC, SIEM & detection engineering — incident response, Microsoft Sentinel, KQL, Sigma, SC-200 outcomes.
5. Digital forensics & malware analysis — acquisition and timelines (COMP832/843); static/dynamic malware analysis, Ghidra, YARA.
6. Cloud, IoT & application security — cloud IAM/network/logging and CSPM (INFS803), IoT risk (COMP816), SAST/DAST/SCA.
7. AI security & emerging skills — OWASP LLM Top 10, prompt injection, securing AI pipelines, AI for detection, NIST AI RMF.
8. Research methods & dissertation — researchable question, ethics, method, proposal (ENGE817).
9. Career, cybercrime law & consolidation — NZ cybercrime law and policy (COMP844), target role, resume, interview prep, final review.

## Course and role views

`src/data/roadmaps.ts` maps Atlas groups to AUT courses (COMP844, COMP832/843,
COMP830, COMP833, COMP821, INFS803, ENGE817) and to target roles (penetration
tester, SOC analyst & digital forensics, application security engineer, security
engineer), plus the three optional brush-up tracks.

## Checks

`npm run check:data` verifies: 72 blocks; every cybersecurity checkpoint
scheduled exactly once; 1–15 checkpoints per block; every group has study
resources and every checkpoint a topic-specific resource row with HTTPS links
and a substantive action; nine phases covering blocks 1–72; the 13-group
security track; and the AUT programme and research-pathway data. `npm run
check:links` audits external URL health.

Programme facts come from AUT's public programme page and should be confirmed
against your own offer and enrolment; the plan is preparatory study, not a
substitute for course teaching or assessment.

## Career timeline and eligibility

The Career page adds a dated timeline (pre-arrival tasks, the March–April 2027
internship round, the March–April 2028 graduate round, the post-study work visa)
and an employer eligibility tracker in `src/data/career-plan.json`. Eligibility
notes come from employer pages and listings checked on the date in that file;
work-rights rules change, so they must be confirmed on each listing.

`npm test` guards two ordering rules: a skill's levels never go backwards across
the weekly plan, and the application checkpoint falls inside the March–April
round for a 22 February start.

## Certifications and cloud platform

Exam-prep groups are built from each vendor's current objectives (checked 7
November 2026): CompTIA Security+ SY0-701 (five weighted domains; SY0-801 is
reported for late 2026), eJPT (four weighted domains), Microsoft SC-200 (skills
outline as of 21 October 2026) and BTL1 (six domains). They are scheduled next to
the skills that feed them: Security+ in Phase 1, eJPT in Phase 3, SC-200 in
Phase 4 and BTL1 in Phase 5. ISC2 CC (outline effective 1 September 2026) sits in
the optional track E as the alternative to Security+. AZ-500 retired on 31 August
2026; SC-500 replaced it and appears as a later-career planning step.

`src/data/certifications.json` drives the certification plan on the Career page,
which shows exam-prep progress and how much of the feeding skill work is done.

The cloud groups use Azure as the primary hands-on platform, because NZ SOC and
security roles lean Microsoft, and name the AWS equivalent for each topic.

## Study plan scope and resources (November 2026 revision)

The weekly plan holds only skills to learn and practise. Job-search activities,
career tasks and exam logistics (booking, exam formats) were removed from it;
exam timing and costs live in the certification plan on the Career page.
Governance stays only where AUT assesses it (risk assessment, security policy,
controls), framed as practical documents.

Each lesson has one place to learn, one hands-on place to practise and a
specific task for its skill. Policy documents and link lists are no longer used
as lessons. Primary resources include Professor Messer's free Security+ course,
TryHackMe free rooms and role paths, OverTheWire Bandit, PortSwigger, OWASP Juice
Shop, LetsDefend, CyberDefenders, Kusto Detective Agency, the Autopsy guide,
crackmes.one, GOAD, Gandalf and USENIX Security papers. Some TryHackMe path rooms
need a paid plan; the free-room guide lists what is free.

The week page shows one numbered lesson list first; planning detail is collapsed
at the bottom. The Atlas opens on the cybersecurity track with skills collapsed.
